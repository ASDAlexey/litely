Обзор

Litely — настольное приложение для автоматического сжатия медиа. Оно работает полностью офлайн. Ваши файлы никогда не покидают устройство, если вы явно не настроите интеграцию (например, загрузку в Jira).

Данные, которые мы не собираем

Litely не содержит аналитики, телеметрии, трекинга или отчётов об ошибках. В частности:

  • Нет аналитики использования или поведенческого трекинга
  • Нет отчётов об ошибках или телеметрии
  • Нет рекламных идентификаторов
  • Нет сбора персональных данных
  • Нет куки или веб-трекинга

Данные, хранящиеся локально

Все данные остаются на вашем устройстве в директории поддержки приложения:

  • Настройки — параметры сжатия, отслеживаемые папки, состояние интерфейса (база данных SQLite)
  • История сжатия — имена файлов, размеры, временные метки обработанных файлов (база данных SQLite)
  • Лицензионный ключ — ваш Pro-ключ, если активирован (база данных SQLite)

Ни одни из этих данных не передаются на какой-либо сервер.

Сетевые соединения

Litely выполняет сетевые запросы только в следующих случаях:

  • Загрузка FFmpeg / Ghostscript — одноразовая загрузка инструментов сжатия из официальных источников при первом запуске
  • Загрузка в Jira (опционально) — при настройке интеграции с Jira сжатые файлы отправляются на ваш экземпляр Jira через REST API с использованием вашего Personal Access Token. Токен хранится локально в SQLite

Chrome-расширение: Litely for Jira

Опциональное расширение браузера связывается с Litely через локальное WebSocket-соединение (127.0.0.1:19836). Оно не:

  • Отправляет данные на внешние серверы
  • Отслеживает историю браузера
  • Получает доступ к содержимому страниц за пределами комментариев Jira
  • Хранит данные в хранилище браузера

Расширение активируется только на страницах Jira и передаёт события вставки в локальное приложение Litely для загрузки файлов.

Сторонние сервисы

Litely не использует сторонние сервисы для аналитики, рекламы или обработки данных. Единственное внешнее взаимодействие — с вашим собственным экземпляром Jira, когда вы явно настроите и используете интеграцию.

Удаление данных

При удалении Litely удаляется приложение. Чтобы удалить все сохранённые данные, удалите директорию поддержки приложения:

  • macOS: ~/Library/Application Support/ru.litely.app/
  • Windows: %APPDATA%/ru.litely.app/
  • Linux: ~/.local/share/ru.litely.app/
