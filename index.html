Десктопное приложение для пакетного сжатия изображений и видео. FFmpeg под капотом, нативная скорость, нулевой трафик в облако.

Скачать для вашей системы

macOS 11+ · Бесплатно · Нативное приложение

Возможности

Видео

  • H.265 (HEVC) — максимальное сжатие
  • H.264 — универсальная совместимость
  • AV1 — новейший стандарт
  • GPU-ускорение (VideoToolbox)
  • 3 уровня качества + CRF

Изображения

  • WebP — оптимальный баланс
  • AVIF — следующее поколение
  • JPEG — MozJPEG оптимизация
  • PNG — сжатие без потерь (OxiPNG)
  • Ресайз и мультиресайз

Автоматизация

  • Отслеживание папок
  • Drag & Drop файлов
  • Пакетная обработка
  • Копирование в буфер обмена
  • Удаление исходников

Инструменты

  • Сравнение до и после
  • Целевой размер файла
  • Конвертация форматов
  • Извлечение аудио
  • История обработки
