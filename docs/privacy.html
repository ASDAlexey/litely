Privacy Policy

Last updated: May 10, 2026

Overview

Litely is a desktop application for automatic media compression. It is designed to work entirely offline. Your files never leave your device unless you explicitly configure an integration (e.g., Jira upload).

Data We Do Not Collect

Litely does not include any analytics, telemetry, tracking, or crash reporting. Specifically:

  • No usage analytics or behavioral tracking
  • No crash reports or error telemetry
  • No advertising identifiers
  • No personal data collection
  • No cookies or web tracking

Data Stored Locally

All data remains on your device in the application support directory:

  • Settings — compression preferences, watched folders, UI state (SQLite database)
  • Compression history — file names, sizes, timestamps of processed files (SQLite database)
  • License key — your Pro license key, if activated (SQLite database)

None of this data is transmitted to any server.

Network Connections

Litely makes network requests only in the following cases:

  • FFmpeg / Ghostscript download — one-time download of compression tools from official sources on first launch
  • Jira upload (optional) — when you configure Jira integration and trigger an upload, compressed files are sent to your Jira instance via its REST API using your Personal Access Token. The token is stored locally in SQLite

Chrome Extension: Litely for Jira

The optional browser extension communicates with the Litely desktop app via a local WebSocket connection (127.0.0.1:19836). It does not:

  • Send any data to external servers
  • Track browsing history
  • Access page content outside of Jira comment fields
  • Store any data in browser storage

The extension only activates on Jira pages and forwards paste events to the local Litely app for file upload.

Third-Party Services

Litely does not use any third-party services for analytics, advertising, or data processing. The only external communication is with your own Jira instance when you explicitly configure and use the Jira integration.

Data Deletion

Uninstalling Litely removes the application. To remove all stored data, delete the application support directory:

  • macOS: ~/Library/Application Support/ru.litely.app/
  • Windows: %APPDATA%/ru.litely.app/
  • Linux: ~/.local/share/ru.litely.app/
