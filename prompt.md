Создай продающий лендинг для десктопного приложения Litely — автоматического компрессора видео и изображений.

О продукте

Litely — кроссплатформенное десктопное приложение (macOS, Windows, Linux) для автоматической пакетной компрессии медиафайлов. Пользователь просто добавляет папки для наблюдения — и все новые видео и изображения сжимаются
автоматически. Построено на Tauri 2 (Rust) + Angular 21, работает нативно без Electron.

Фичи для лендинга (все блоки)

Hero-секция

- Заголовок: акцент на автоматизацию сжатия медиа одним действием
- Подзаголовок: "Добавь папку — всё остальное Litely сделает сам"
- CTA-кнопка скачивания (macOS / Windows / Linux)
- Визуал: анимация drag & drop файла → сжатый результат с показом уменьшения размера

Блок "Автоматическое наблюдение за папками" (Watch Folders)

- Наблюдение до 3 папок одновременно
- Автодетект новых файлов в реальном времени
- Сохранение настроек между перезапусками
- Умная фильтрация (игнорирует скрытые, уже сжатые, output-файлы)

Блок "Сжатие видео" (Video Compression)

- Кодеки: H.264 (максимальная совместимость), H.265/HEVC (лучший баланс), AV1 (максимальное сжатие)
- GPU-ускорение через VideoToolbox на macOS
- 3 пресета качества: Compact, Optimal, Maximum
- Двухпроходное кодирование для лучшего соотношения качество/размер
- Конвертация форматов: MP4, MOV, AVI, MKV, WebM, FLV, GIF
- Извлечение аудиодорожки из видео
- Ресайз видео (fit/width/height)
- Целевой размер файла — автоподбор качества под заданный вес

Блок "Сжатие изображений" (Image Compression)

- Форматы: WebP, AVIF, JPEG, PNG, HEIC/HEIF, BMP, TIFF
- Кодеки на выбор: WebP (по умолчанию), AVIF (макс. сжатие), JPEG (универсальный), PNG (без потерь)
- Ползунок качества 1–100
- Удаление метаданных EXIF и ICC
- Режим Max Effort (медленнее, но лучше сжатие)
- Целевой размер в KB — автоматический подбор качества
- Пакетный ресайз — генерация нескольких размеров из одного изображения
- Визуальное сравнение до/после со слайдером

Блок "Управление задачами" (Task Management)

- Пауза / возобновление / отмена отдельных задач
- Прогресс в реальном времени с оценкой оставшегося времени
- История задач с автоочисткой через 7 дней
- Группировка по датам (сегодня / дата)
- Показ: входной размер → выходной размер → % уменьшения
- Прогресс пакетной обработки в системном трее

Блок "Удобство и интеграция с системой"

- Drag & drop файлов прямо в окно приложения
- Системный трей: приложение живёт в трее, не мешает
- Плавающая панель прогресса (always-on-top)
- Автокопирование сжатого файла в буфер обмена
- Автоудаление оригиналов после сжатия (опционально)
- Нативные системные диалоги выбора папок
- Тёмная и светлая тема

Блок "Нативная скорость" (Performance)

- Построен на Tauri 2 + Rust — не Electron, минимальное потребление памяти
- FFmpeg 6.1.1 под капотом для видео
- Swift-модуль VideoToolbox для аппаратного ускорения на macOS
- Виртуальный скроллинг списка задач — плавная работа с тысячами файлов
- Zoneless Angular 21 — мгновенный отклик интерфейса

Блок "Платформы"

- macOS 11.0+ (с GPU-ускорением)
- Windows (NSIS-установщик)
- Linux (AppImage, DEB)

Блок "Сценарии использования" (Use Cases)

- Контент-креаторы: сжимай видео перед загрузкой на YouTube/TikTok
- Фотографы: пакетная оптимизация для веб-галерей
- Видеоредакторы: быстрое сжатие для ревью и шеринга
- SMM-менеджеры: оптимизация медиа перед публикацией
- Разработчики: сжатие ассетов для проектов
- Любой, кто хочет освободить место на диске

Footer

Требования к дизайну

1. Стиль: современный, минималистичный, тёмная тема по умолчанию с возможностью переключения на светлую. Вдохновление: Linear, Raycast, Arc Browser
2. Анимации: плавные scroll-анимации появления секций, hover-эффекты на кнопках и карточках, анимированные числа (счётчик сжатия). Используй CSS-анимации и Intersection Observer
3. Типографика: системные шрифты (Inter или SF Pro если доступны), чёткая иерархия заголовков
4. Адаптивность: полностью responsive (mobile-first), десктоп, планшет, телефон
5. Иллюстрации: используй CSS-графику, градиенты и SVG-иконки. Никаких placeholder-картинок — всё должно быть реализовано в коде
6. Цвета: градиенты от фиолетового к синему как акцентные, тёмно-серый фон, белый текст. Для светлой темы — инвертированные
7. Секции: каждая фича — отдельная секция с визуальным элементом (схема, анимация, CSS-иллюстрация)

Технические требования

1. Один HTML-файл со встроенными CSS и JS (single-file landing)
2. Vanilla HTML/CSS/JS — без фреймворков и сборщиков
3. Семантическая вёрстка: header, main, section, footer
4. Performance: минимальный JS, CSS-анимации где возможно, lazy-появление секций
5. SEO: мета-теги, Open Graph, structured data
6. Accessibility: правильные ARIA-атрибуты, клавиатурная навигация, контраст текста
7. Smooth scroll между секциями через навигацию
8. Кнопка скачивания определяет ОС пользователя и предлагает нужную версию
